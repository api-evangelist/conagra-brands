# Conagra Brands

> Conagra Brands is a North American branded consumer packaged goods (CPG) food company
> headquartered in Chicago, Illinois. This file is generated by API Evangelist from the
> apis.io catalog record for Conagra Brands and from live probes of Conagra's public
> hosts on 2026-09-05. It is NOT published by Conagra.

Conagra publishes no developer portal, no API documentation, no SDKs and no terms of use
for API access. One public, undocumented API surface was found by probe and is described
below.

## APIs

- [Conagra Brand Sites API](https://brands-api.conagrafoods.com/): Read-only OData v3
  service backing Conagra's consumer brand websites. Base URL
  https://brands-api.conagrafoods.com/odata. No authentication - anonymous HTTPS GET.
  Service version v1.2023.0224.1.

### Conagra Brand Sites API - what actually works

- `GET /odata` - AtomPub service document listing six entity sets.
- `GET /odata/Products` - 2,267 products. 100 per page, `odata.nextLink` for the next page.
- `GET /odata/Brands` - brand codes (e.g. `WES`, `SM`).
- `GET /odata/Brands('WES')` - read one brand by key.
- Query options honoured: `$top`, `$skip`, `$select`, `$filter`, `$orderby`, `$inlinecount=allpages`.
- Read-only: `POST` is not routed and returns 404.

### Known limitations (probed, not documented by Conagra)

- `GET /odata/$metadata` returns 404 even though every response references it, so no
  OData client can bootstrap a model from the service. Standard OData tooling will fail.
- Four of the six advertised entity sets do not resolve: `Labels`, `LabelImages`,
  `ProductCategories`, `RecipeCollections` all return 404.
- No rate limits are documented and no rate-limit headers are returned.
- No terms of service, plans, pricing, sign-up or support channel exist for this API.
- ASP.NET verbose errors are enabled; unrouted paths return an HTML page carrying a
  .NET stack trace.
